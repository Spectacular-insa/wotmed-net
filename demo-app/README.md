# Wotmed-Net Demo App & Deception Tester

**Lead:** Eman Mohammednur Ahmed

## Overview

The `demo-app` provides the reference application used to demonstrate
and test the Wotmed-Net active defense system.

The application is based on the existing Student Management System
and will be adapted for controlled security testing and deception
experiments.

## Responsibilities

This component covers:

- Reference application
- Deception mechanisms
- Honeytokens and canary resources
- Deception triggers
- Application verification and testing
- Integration with Wotmed-Net telemetry

## Security

All testing and deception mechanisms are intended for the authorized
Wotmed-Net development and testing environment.

No real credentials, production secrets, or production data will be
used.
